# Website Features

## Fuel entry
Manual entry of date/time, event type, litres, fuel price, total cost, odometer, meter photo and notes.

## Fuel cycle
Refill/start -> driving -> fuel empty/end. Open cycles remain visible until valid ending data is recorded.

## History
Chronological records, date filters, event filters, vehicle filter, details, edit and delete with confirmation.

## Dashboard
Fuel used, total cost, distance, average km/L, L/100 km, cost/km, completed cycles and open cycles.

## Analytics
Date-range charts for consumption, cost, distance, fuel-price trends and km/L trends. Clearly label incomplete data.

## DOCX report
Select From Date, To Date and vehicle. Export summary KPIs, records, completed-cycle analytics, charts, available odometer photos, notes and incomplete-cycle warnings.

## Evidence photos
Allow photo preview, upload progress, replacement/removal and Firebase Storage persistence.
